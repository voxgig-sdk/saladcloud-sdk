## Why this SDK exists

It is on the admin repository's **vergleich** list: SDKs built with the Voxgig
toolchain to compare it with the generators on voxgig.com/sdk/comparisons, one
API per generator. This one is compared with **liblab**.

- **Compared with:** SaladTechnologies/salad-cloud-sdk-javascript 0.9.0-alpha.17, generated by liblab 2.25.53 (`.manifest.json`). SaladCloud also ships liblab SDKs for Python, Go, Java and .NET.
